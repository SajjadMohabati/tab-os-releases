# TabOS — Apple Liquid Glass Desktop OS for Chrome New Tab

**Created by Sajjad Mohabati**

TabOS transforms your Chrome New Tab into a fast, ultra-lightweight **Liquid Glass Desktop OS** — complete with a macOS-style magnification Dock, draggable widgets, live 2-way Chrome Bookmarks sync, floating multi-window desktop apps, Chrome Side Panel integration, Triple Calendar (Jalali / Gregorian / Hijri), Speed Test & Network Monitor, and offline Developer Tools.

## Manual Installation (Chrome / Edge / Brave / Arc)

1. Download the latest `tab-os-vX.Y.Z.zip` from **[Releases](https://github.com/SajjadMohabati/tab-os-releases/releases/latest)** and unzip it to a permanent folder.
2. Open `chrome://extensions` in your browser.
3. Enable **Developer mode** (top-right toggle).
4. Click **Load unpacked** and select the unzipped folder (the folder containing `manifest.json`).
5. Open a new tab (`Cmd+T` / `Ctrl+T`) and enjoy **TabOS**!

## Key Highlights

- **Apple Liquid Glass Engine** — Customizable blur, vibrancy, Fresnel rim glow, live aurora wallpaper, and Dark/Light themes.
- **macOS Magnification Dock** — Reorder via drag & drop, drag out to unpin, full Dock Settings studio (size, zoom strength, system tools).
- **Live 2-Way Chrome Bookmarks Sync** — Direct sync with Chrome Bookmarks plus permanent localized `TabOS Tools` & `TabOS Picks` folders.
- **Multi-Window Desktop OS & Side Panel** — Resizeable 8-direction floating windows for native tools (Calculator, Notes, Sticky Notes, Speed Test, Calendar, History, Folder Tree) and embedded web apps (e.g. Telegram Web) via right-click menu.
- **Bilingual (English & فارسی)** — Full RTL/LTR support and Triple Calendar (Jalali, Gregorian, Hijri).
- **Zero Telemetry & Ultra-Lightweight** — 100% local storage, lazy-loaded apps, and zero idle background bloat. See [Privacy Policy](./PRIVACY_POLICY.md).
